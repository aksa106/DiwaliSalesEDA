# Diwali Sales EDA

A Python Exploratory Data Analysis (EDA) project on the Diwali Sales dataset using **Pandas**, **NumPy**, **Matplotlib**, and **Seaborn**.

## Objectives

- Understand the dataset
- Clean and prepare the data
- Perform statistical exploration
- Analyze customer purchasing behavior
- Generate business insights
- Document findings

## Project Versions

### Version 1
Recreated the reference project to understand the complete EDA workflow.

### Version 2 (Planned)
An improved version focusing on:
- Descriptive statistics
- Five-number summary
- Distribution analysis
- Outlier detection
- Correlation analysis
- Stronger statistical reasoning
- Better business insights

## Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
